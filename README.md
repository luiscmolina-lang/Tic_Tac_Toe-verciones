# Tic Tac Toe - Versiones

Este proyecto contiene 4 versiones diferentes de una aplicación de Tic Tac Toe desarrollada para Eclipse en WildFly.

## Estructura del Proyecto

El repositorio está organizado en las siguientes carpetas:

- **Version_1/** - Primera versión de la aplicación
- **Version_2/** - Segunda versión de la aplicación
- **Version_3/** - Tercera versión de la aplicación
- **Version_4/** - Cuarta versión de la aplicación

Cada carpeta contiene los archivos necesarios de Eclipse/WildFly para su respectiva versión.

## Descripción

Cada versión representa una iteración diferente del juego de Tic Tac Toe, con posibles mejoras y cambios en la implementación.

### Cómo usar

1. Descarga la carpeta de la versión que desees
2. Importa el proyecto en Eclipse
3. Configura el servidor WildFly
4. Despliega la aplicación
